# platforms

Владелец карточек поверхностей и матрицы агентов. Механика ранжирования, веса и проценты сюда не входят: спорные тезисы живут в evidence.md, процедуры у маршрутов.

## Вход

- Поверхность или агент, нужное свойство (роль агента, отношение к robots.txt, отчёт для владельца, режим, интерфейс ссылок), рынок.

## Процедура

1. Найди карточку поверхности или строку матрицы.
2. Свойство с пометкой «требует проверки» или карточка с датой сверки «не сверено» → сверь свойство с первичной документацией вендора из карточки, укажи в ответе URL и дату сверки. При правке этого файла обнови поле «Дата последней сверки».
3. Сверить нельзя (нет доступа, нет документации) → по поверхности выдай план ручной проверки без вердикта. Механику поверхности не утверждай.
4. Свойства интерфейса, роли агентов и названия отчётов меняются: проверяй их при каждом использовании, а не по памяти.
5. Пометка «вторичный источник» означает статью или вендорское исследование, а не документацию платформы. Как основание для штрафа, обещания или изменения сайта не используется.
6. Порядок карточек: глобальные, затем рынок РФ. Если пользователь выбрал RU-first, меняется только порядок.

## Выход

Свойство, первичный источник, дата сверки либо «не сверено» и план проверки. Не возвращать: факторы ранжирования, веса, проценты цитирования, гарантии появления в ответе.

## Матрица агентов

Классы:

- **search** — автоматический обход для поиска и обнаружения. Влияет на включение в поисковую поверхность вендора.
- **training** — обход для возможного обучения моделей. Запрет — законный выбор владельца и сам по себе не выводит сайт из поиска.
- **user-initiated** — открытие страницы по запросу конкретного пользователя. Вендоры могут не применять к нему robots.txt.
- **управление использованием** — токен robots.txt или настройка без отдельного краулера: определяет, как вендор использует уже полученный контент.

Ориентиры из решения конфликтов: OAI-SearchBot и Claude-SearchBot для поиска, GPTBot и ClaudeBot для обучения, ChatGPT-User и Claude-User для пользовательских открытий, Googlebot и Google-Extended имеют разные функции. ## Карточки поверхностей

Поля карточки: доступ, отчёты для владельца, свойства из исходников с типом источника, что не переносится, первичная документация, дата последней сверки. Замер ответов по протоколу visibility.md.

### Google Search, AI Overviews, AI Mode

- **Доступ:** `Googlebot`. `Google-Extended` на включение в Search не влияет (матрица). Как управлять показом контента именно в AI Overviews и AI Mode — требует проверки по документации Google.
- **Заявления Google (через исходник ai-seo, цитата руководства):** генеративные функции Search опираются на основные системы ранжирования и качества. Специальные файлы и разметка для AI Overviews и AI Mode не требуются. Отдельного контента для AI писать не нужно. Требует проверки актуальности формулировок.
- **Query fan-out:** Google описывает разворачивание запроса в связанные подзапросы (пример из исходника: «how to fix lawns»). Требует проверки по документации. Применение — content.md и plan.md.
- **Отчёты для владельца:** отчёты Search Console по AI-функциям и переключатель запрета использования контента в них (вторичный источник S101). Путь в интерфейсе, даты запуска и существование фильтра «Search type → AI Overviews» требуют проверки (RU F39).
- **Вторичные источники, требуют проверки:** политики спама распространяются на AI Overviews и AI Mode (S107, S068, S069). Клик по цитате AI Overview добавляет к URL `#:~:text=` (S004), использование в measure.md.
- **Не переносится:** доля запросов с AI Overviews, пересечение с топ-10, доля пассажей, доля Shopping, «E-E-A-T weighted heavily», эффект запрета AI на клики (S065) — evidence.md.
- **Первичная документация:** https://developers.google.com/search/docs/fundamentals/ai-optimization-guide ; https://developers.google.com/crawling/docs/crawlers-fetchers/google-common-crawlers
- **Дата последней сверки:** не сверено.

### Gemini

- **Доступ:** `Google-Extended` управляет частью использования контента для обучения и grounding Gemini (матрица).
- **Свойства из исходников, требуют проверки:** grounding через Google Search (RU-исходник без первичного источника).
- **Не переносится:** доля цитат сайтов бизнеса в локальных запросах, доля совпадения источников при повторе, пересечение с ChatGPT, «наследует E-E-A-T» — evidence.md.
- **Первичная документация:** https://developers.google.com/crawling/docs/crawlers-fetchers/google-common-crawlers (для `Google-Extended`). Для механики ответа в исходниках нет.
- **Дата последней сверки:** не сверено.

### Bing и Microsoft Copilot

- **Доступ:** `Bingbot`. Copilot опирается на индекс Bing (исходники ai-seo, RU) — требует проверки. Bing допустим как диагностика собственной поверхности. Вывод о причинах отсутствия в ChatGPT из Bing не делай (RU F4-F5).
- **Отчёты для владельца:** Bing Webmaster Tools. AI-отчёт (AI Performance, бета с февраля 2026: цитирование в Copilot и AI-ответах Bing, grounding queries, без кликов; S100: интенты, темы, доля цитат, сравнение) — требует проверки названия, состава и статуса.
- **Управление использованием:** по S066 с 1 марта 2027 `NoArchive` и `NoCache` перестают считаться предпочтением для обучения и grounding, настройки задаются в Bing Webmaster Tools. Дата и механизм требуют проверки.
- **Индексация:** IndexNow для отправки новых и изменённых URL. Поддержку и порядок подключения сверяй по документации.
- **Вторичный источник, требует проверки:** Microsoft подтверждал использование schema Copilot (S032).
- **Не переносится:** порог скорости загрузки, кратность цитирования LinkedIn и Reddit — evidence.md, offpage.md.
- **Первичная документация:** http://www.bing.com/bingbot.htm ; https://www.bing.com/webmasters
- **Дата последней сверки:** не сверено.

### ChatGPT search

- **Доступ:** `OAI-SearchBot` для включения в поиск, `ChatGPT-User` для открытий по запросу пользователя, `GPTBot` для обучения (матрица).
- **Источник выдачи:** исходники расходятся. ai-seo и RU описывают индекс на базе Bing, S002 — собственный индекс OpenAI с малым пересечением с Bing и несколько конвейеров. Требует проверки. Индексация и в Google, и в Bing — разумная страховка, но не объяснение отсутствия.
- **Режимы:** быстрый режим и режим рассуждения различаются по исходникам (S002, вторичный). Быстрый работает по title и короткому фрагменту без открытия страницы. Режим рассуждения делает больше поисков и открывает страницы через `ChatGPT-User`. Требует проверки. В журнале visibility.md режим фиксируется отдельно.
- **Свойства из исходников, требуют проверки:** кеш прочитанных страниц в Markdown, при конвертации удаляются скрипты, iframe и JSON-LD, alt остаётся (S002, гипотезы — evidence.md). Товары и локальные запросы идут через фиды и листинги, а не веб-поиск (S002). Открытия в режиме рассуждения не несут `utm_source` (S002, measure.md). ChatGPT Shopping включается чаще по категории товара (Profound, наблюдение; ecommerce.md). Браузер ChatGPT Atlas закрыт 9 августа 2026 (S078). Модель «ChatGPT 5.6» и смена форматов цитирования после неё (AI 11-13).
- **Не переносится:** 200 символов после H1, 74% / 7%, доля Instant, 30 минут свежести кеша, 1500+ слов, `/en/`-зеркало как множитель, доли Wikipedia/Reddit/Forbes, связь с числом ссылающихся доменов — evidence.md, требуют проверки (RU F1, F33, F4-F5, Plugin 20).
- **Первичная документация:** https://developers.openai.com/api/docs/bots ; https://openai.com/gptbot ; https://openai.com/searchbot
- **Дата последней сверки:** не сверено.

### Perplexity

- **Доступ:** `PerplexityBot` для поиска, `Perplexity-User` для открытий по запросу (матрица).
- **Свойства из исходников, требуют проверки:** ответы показывают источники кликабельными ссылками (ai-seo). Источник выдачи: собственный индекс в сочетании с Google, Brave или Bing — исходники расходятся.
- **Не переносится:** белые списки доменов, PDF-приоритет, time-decay, частота публикаций, усиление от FAQ-schema, плотность цитат, доля «призрачных» цитат (S091) — evidence.md (RU F4-F5, F3).
- **Отчёты для владельца:** в исходниках нет. Замер по visibility.md.
- **Первичная документация:** https://docs.perplexity.ai/docs/resources/perplexity-crawlers ; https://perplexity.ai/perplexitybot
- **Дата последней сверки:** не сверено.

### Claude

- **Доступ:** `Claude-SearchBot` для поиска, `Claude-User` для открытий по запросу, `ClaudeBot` для обучения. Решение по каждому отдельно (матрица).
- **Источник выдачи:** веб-поиск через Brave Search по вторичным источникам (S014, ai-seo, RU). Требует первоисточника (RU F4-F5).
- **Ручная проверка:** наличие страниц в выдаче search.brave.com по бренду и ключевым запросам. Отправка URL: search.brave.com/submit-url (только уведомление краулера, без кабинета и sitemap; результат по рефералам search.brave.com в measure.md).
- **Не переносится:** 79,2% цитат из топ-10 Brave, доля промптов с поиском, детерминированность fan-out, «селективность», год в title — evidence.md.
- **Первичная документация:** https://privacy.anthropic.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler
- **Дата последней сверки:** не сверено.

### Meta AI и Muse

- **Доступ:** `meta-webindexer` для поиска Meta AI, `meta-externalagent` для обучения, `meta-externalfetcher` для пользовательских открытий, `facebookexternalhit` для превью (матрица).
- **Свойства из исходников, требуют проверки:** Meta не документирует индекс и выбор источников Meta AI. Агент Muse (сентябрь 2026, вторичный источник) ищет по каталогу Shopify и оформляет покупки (AI 11-13). Утверждения о «ранжировании в Muse» не проверены.
- **Отчёты для владельца:** в исходниках нет. Замер по visibility.md.
- **Первичная документация:** https://developers.facebook.com/docs/sharing/webmasters/web-crawlers
- **Дата последней сверки:** не сверено.

### Google Business Profile и Merchant Center

- **Свойства из исходников, требуют проверки:** Google выделяет фиды Merchant Center и Google Business Profile для видимости товаров и услуг в AI Search, Business Agent для диалога с клиентами. UCP упоминается как будущий протокол торговых взаимодействий агентов (AI 11-13). Требования к продавцам и фидам сверяй по документации платформы.
- **Применение:** local.md для профиля, ecommerce.md для фида.
- **Первичная документация:** в исходниках нет.
- **Дата последней сверки:** не сверено.

## Инструменты

Список сторонних инструментов выдавай только по запросу пользователя, с критериями: какие поверхности и рынки покрывает, как получает ответы (API, браузер, ручной ввод), есть ли экспорт сырых ответов с датой и режимом, вендорский ли это продукт. Без партнёрских пометок и рекламы (AI 25-26). Сканеры агентской готовности из исходников (Is Agentic, Frase Agent Readiness Checker, Fern Agent Score) и спецификация AgentReady — вендорские: их баллы не являются результатом technical, проверки сверяй по сценарию technical.md.
