# seo-aeo-geo

Набор из двух самостоятельных навыков агента для органического поиска и AI-ответов: SEO, AEO (ответы) и GEO (генеративный поиск). В корне своего `SKILL.md` нет — триггеры есть только у навыков в `skills/`.

| Навык | Когда | Что возвращает |
|---|---|---|
| [seo-aeo-geo](skills/seo-aeo-geo/SKILL.md) | Аудит, техника, контент существующих страниц, сущность, внешний след, замер AI-видимости, local, ecommerce, рефреш, план | Находки, правки фрагментами, очередь работ, замеры |
| [seo-article-writer](skills/seo-article-writer/SKILL.md) | «Напиши статью», гайд, сравнение, обзор с нуля или полностью заново | Бриф, план на согласование, черновик, реестр утверждений, JSON-LD |

Подробное описание маршрутов, скриптов и результатов аудита и Arena — [skills/seo-aeo-geo/README.md](skills/seo-aeo-geo/README.md).

## Установка

Скопируйте нужную папку из `skills/` в каталог навыков своей оболочки (для Claude Code — `~/.claude/skills/`). Каждый навык самодостаточен; `seo-article-writer` использует правила текста из `seo-aeo-geo/references/content.md`, поэтому лучше ставить оба. `commands/aeo.md` — необязательная пересылка старого вызова `/aeo` в `seo-aeo-geo`.

## Правила набора

- Каждый навык самодостаточен: папку можно скопировать отдельно.
- Ссылки между навыками — по имени навыка, не относительным путём.
- Аудит передаёт просьбу о полном тексте статьи в `seo-article-writer`; правила качества текста живут только в `content.md`.
